## ⚖️ 三条铁律

1. **70/30 原则**：动手写代码占 70%，看教程最多 30%
2. **关掉重写**：算法题看懂题解后必须关掉从零重写，才算学会
3. **不断链**：状态再差也保底 1 道题 + 15 分钟，全有或全无 = 弃坑
